# Skills excluded from v1

The following upstream skills are deliberately not active:

- `setup-matt-pocock-skills` - would configure a competing tracker and documentation layout.
- `triage` - introduces a second state machine and can mutate labels/issues.
- `implement` - does not model Saketos Task Packet, lease, gates and release verification.
- `wayfinder` - creates a parallel map, claim model and child-issue queue.
- `to-spec` - may publish and mark work ready without portfolio planning.
- `to-tickets` - may create a parallel executable queue and dependencies.

Their ideas may be reviewed later, but none may be invoked or installed from this repository in v1.
